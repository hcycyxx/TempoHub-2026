# TempoHub 网易云歌词 v1.0.9

## 本次修复

- 本机网易云进度接口超时后，不再让旧歌信息卡住新歌歌词。
- 自动改用歌名查找歌词，并以电脑现有的播放进度继续同步。
- 精确进度恢复后自动切回；界面提示改为中文，不再显示英文原始错误。
- 本机连接固定绕过系统代理，减少 9222 端口连接超时。

## 文件

| 文件 | 用途 |
| --- | --- |
| `TempoHub-NetEase-Installer-v1.0.9.exe` | Windows 安装器，装入已验收的 v2 补丁与控制台 |
| `TempoHub-NetEase-v1.0.9-source-docs.zip` | 源码、中文文档及构建说明 |
| `SHA256SUMS.txt` | 两个附件的 SHA-256 校验值 |

## 安装与更新

先退出补丁相关窗口，保留旧补丁目录；运行新安装器后，打开新的控制台。网易云需以 `--remote-debugging-port=9222` 启动，精确进度才能使用。控制台左侧可手动拉起 TempoHub 和网易云，不会自动中断播放。

## 验证范围

- 静态检查：Python 3.9 语法通过；补丁 EXE 内 PYZ 模块检查通过；安装包构建成功。
- 用户实际验收：固件升级后，网易云歌词时间轴恢复并显示，测试通过。
- 未进行的验证：本次未在新装机环境执行完整安装器，也未把该安装包作为独立实机测试项。

## 兼容性与限制

仍依赖官方 EDIFIER TempoHub 的 Python 3.9 运行库，官方安装目录不作修改。歌名回退依赖网易云公开接口；精确进度仍依赖 9222 调试端口。`v3` 备用文件不属于本次发布。
